# Minecraft 音乐命令方块生成器

[![在线使用](https://img.shields.io/badge/在线使用-点击跳转-2b8cbe?style=flat-square)](https://zero-raltal.github.io/MCBE-CBNoteBlock/)
[![许可证](https://img.shields.io/badge/license-MIT-green?style=flat-square)](LICENSE)

> 将 MIDI / NBS 文件一键转换为 Minecraft 基岩版 1.19+ / Java 版 1.13+ 的音乐命令方块指令，内置预览播放、瀑布图可视化、在线曲库、CBND 导入导出与结构文件导出。

---

## 功能特点

- **多格式支持** – 支持上传 `.mid` / `.midi` / `.nbs` / `.cbnd` 文件，自动解析音符和乐器信息。
- **双平台支持** – 支持 **基岩版 BE 1.19+** 与 **Java 版 JE 1.13+**，按平台生成对应 `playsound` 指令。
- **精确指令生成** – 生成的命令精确匹配原曲音高与节奏，支持 **乐器映射**、**Harp Only** 和 **自定义音色** 三种模式。
- **实时预览** – 内置 Web Audio 合成器，可在浏览器中试听生成效果，播放速度可调，支持拖拽进度条跳转。
- **瀑布图可视化** – 动态显示音符序列，当前播放位置高亮，方便查看配器与旋律走向。
- **低性能模式** – 自动检测播放丢 tick，必要时暂停瀑布图动态效果，点击画布即可恢复。
- **一键复制 / 导出** – 每条连锁命令均可独立复制，也可一键导出全部指令为文本文件。
- **导入到游戏** – 内置复制器弹窗，可逐条复制命令，适合手机端或手动布置命令方块。
- **CBND 格式** – 支持导出 `.cbnd` 位压缩序列，并支持再次导入，文件体积更小。
- **结构文件导出** – 支持导出 **Java `.nbt`** 与 **基岩版 `.mcstructure`** 结构文件，可直接用结构方块加载，无需手动输入命令。
- **在线曲库** – 内置在线歌单，支持搜索、分页、跳转、随机推荐，点击即可加载并播放。
- **主题配色** – 内置经典绿、神秘黄、晴空蓝三套主题，并支持跟随系统深色模式。

## 使用方法

### 1. 上传音乐文件

点击「上传文件」按钮，选择你的 `.mid` / `.midi` / `.nbs` / `.cbnd` 文件。  
解析成功后，页面会显示音符总数、时长、乐器组等信息。

也可以直接在「在线曲库」中选择歌曲，点击后自动加载并播放。

### 2. 调整参数（可选）

- **平台**：  
  - **BE 1.19+** – 基岩版命令格式，支持自定义音色。  
  - **JE 1.13+** – Java 版命令格式，使用 `minecraft:block.note_block.*` 音色。
- **音色模式**：  
  - **乐器映射** – 根据 MIDI 程序号或 NBS 乐器 ID 映射到对应游戏音色。  
  - **Harp Only** – 将所有非打击乐器统一为竖琴音色，适合简单复刻或节省命令数量。  
  - **自定义音色** – 仅 BE 版可用，例如 `note.pling`，只改变指令生成，不改变预览效果。
- **八度移调**：可将所有音符整体移调（±4 个八度）。
- **MIDI 优化**：开启后自动对齐 20 tick/s，防止节奏变乱。
- **预览速度**：拖动滑块调节播放速度（0.10x ~ 5.00x）。

### 3. 预览音频

点击「播放」按钮即可在浏览器中试听当前生成的音乐。  
进度条支持点击和拖拽跳转，点击「停止」可停止播放并重置进度。

### 4. 获取命令方块指令

页面下方提供：

1. **聊天栏输入** – 计分板创建和初始化命令。  
2. **脉冲命令方块** – 重置播放进度。  
3. **循环命令方块** – 每 tick 增加计分板分数。  
4. **连锁命令方块** – 所有生成的 `playsound` 连锁命令，每条命令均带有复制按钮。

### 5. 复制或导出

- 点击单条命令旁的「复制」按钮，可复制该条命令。
- 点击「复制循环指令」或「复制全部连锁指令」可批量复制。
- 点击「导出为文件」可将全部命令保存为 `.txt` 文本文件。
- 点击「导出为 CBND 序列」可保存为 `.cbnd` 文件。
- 点击「导入到游戏」可打开复制器弹窗，逐条复制命令。
- 点击「导出为结构文件」可导出：
  - Java 版：`.nbt` 结构文件；
  - 基岩版：`.mcstructure` 结构文件。

### 6. 在游戏中布置命令方块

手动布置时，按页面提示依次放置：

1. **聊天栏**输入计分板创建和初始化命令。  
2. **脉冲命令方块**（紧贴循环命令方块）执行计分板重置命令。  
3. **循环命令方块**（无条件、红石控制）执行累加 tick 的命令。  
4. **连锁命令方块**（无条件、始终活动）按顺序放置，内容即为生成的 `playsound` 命令。  

> 注意：连锁命令方块的顺序通常不影响触发（因为播放条件基于计分板 `t` 的值），但建议按生成顺序放置。  
> 使用结构文件导出时，命令方块会自动排列，直接用结构方块加载即可。

## 技术说明

- **MIDI 解析**：支持标准 MIDI 文件（格式 0/1），自动合并多音轨，处理音符开/关事件和程序切换。
- **NBS 解析**：兼容 Note Block Studio 的 v0 / v1 / v2 / v3 / v4 / v5 / v6 版本，读取乐器、层、自定义音色等信息。
- **CBND 解析**：使用位压缩存储音符、乐器与 tick，体积更小，可重复导入。
- **音频合成**：使用 Web Audio API，采样为内置 OGG 样本（Base91 编码），根据音符频率实时调整播放速率，提取自游戏内音符盒音色。
- **命令生成逻辑**：利用计分板 `t` 记录 tick 计数，按平台生成 `playsound` 命令，精确触发对应音符。
- **结构文件生成**：自动生成命令方块阵列，支持 Java `.nbt` 与基岩版 `.mcstructure`。
- **瀑布图**：Canvas 实时绘制，按 tick 分桶，当前播放位置高亮。
- **低性能模式**：检测到播放丢 tick 时自动停用瀑布图动态效果，点击画布恢复。
